# 故障排查

## 其他电脑打不开网页

- 确认所有电脑连接同一个局域网或热点。
- 使用服务端电脑的局域网 IP，不要在其他电脑上访问 `localhost`。
- 允许 Node.js 通过系统防火墙。
- 暂时关闭 VPN、代理和访客网络隔离。
- 确认启动终端仍在运行，且显示的端口是 `3000`。

## 设备没有声音

- 在每台被控端主动点击一次“启用声音”或“准备播放”。
- 检查浏览器标签页是否静音。
- 检查控制端给该设备设置的音量。
- 校准音是高频短音，先把系统音量调到合适水平再测试。

## 媒体显示已分发但不能播放

- 查看对应设备是否显示“需点准备”。
- 点击被控端的“准备播放”后再从控制端播放。
- 推荐使用 Chrome 或 Edge。
- 如果更换了媒体文件，应重新等待该文件达到 `100%`。

## 上传或分发很慢

- 优先使用有线网络或 5GHz Wi-Fi。
- 手机热点速度和稳定性通常较差。
- 上传期间不要让服务端电脑休眠。
- 大文件会先上传到服务端，再由每台被控端独立下载；进度以每台设备显示为准。
- 传输中断后重新选择同一个文件，浏览器会尝试继续尚未完成的分片。

## 多屏看起来切割不正确

- 确认控制端的设备顺序和实际屏幕从左到右一致。
- 所有被控端尽量使用相同的全屏状态和浏览器缩放比例。
- 播放期间不要临时增加、减少或重新排列设备。

## 时间仍有细微差异

- 先完成一次“静止时间”和“自动校准”。
- 用同一张照片拍到所有屏幕后，在被控端执行 `1ms` 手动微调。
- 使用稳定局域网，避免热点信号频繁波动。

## 端口被占用

如果 `3000` 已被其他程序占用，可以临时指定其他端口：

```bash
npm run dev -- --port 3100
```

此时控制端地址改为：

```text
http://本机IP:3100/admin666
```

## 管理页面安全

`/admin666` 是控制端路由，但它不是账号密码保护。请只在可信局域网内运行，不要直接暴露到公网。
