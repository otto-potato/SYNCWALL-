# 文件与数据说明

## 已包含的内容

- `app/`：控制端和被控端网页
- `worker/`：设备、校准、同步、媒体上传等后端接口
- `db/`：数据库结构定义
- `drizzle/`：数据库迁移记录
- `build/`：本地媒体存储、请求日志过滤和构建适配
- `public/`：公开静态资源
- `tests/`：路由、日志和时间码自动化测试
- `.openai/hosting.json`：数据库与媒体存储的逻辑绑定名称
- `package.json`、`package-lock.json`：依赖清单和固定版本

## 未包含的内容

- `node_modules/`
- `dist/`、`.next/`、`.vinext/`
- `.wrangler/`
- `.syncwall-media/`
- `.git/`
- 已上传的媒体和本地数据库
- 原项目的云端站点编号

## 启动后自动生成

- `node_modules/`：执行 `npm install` 后生成的依赖
- `.wrangler/`：本地数据库和运行状态
- `.syncwall-media/`：本地上传的视频、音频和图片
- `dist/`：执行 `npm run build` 后生成的构建文件

这些目录都在 `.gitignore` 中，不属于纯净源码。

## 迁移到另一台电脑

直接复制整个 `syncwall-server-clean` 文件夹，然后在新电脑执行：

```bash
npm install
npm run dev
```

因为纯净版不携带依赖和运行数据，新电脑会得到新的本地数据库和媒体目录。
